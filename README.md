>

**SpeakerTest** is a desktop audio testing application for Windows that helps you test your left and right audio channels, configure tones, review test results, and optionally use text-to-speech narration.

> 🚧 **SpeakerTest is currently in development/beta.** Features may change, bugs may occur, and some functionality may still be experimental.

# 🔄 Test Patterns

SpeakerTest supports multiple testing patterns.

### 🔄 Alternating

Tests channels in an alternating order:

```text
LEFT → RIGHT → LEFT → RIGHT
```

### 🎲 Random

Randomly selects the channel for each round.

### ◀️ Left Only

Only tests the left channel.

### ▶️ Right Only

Only tests the right channel.

The test pattern can be changed from Settings.

# 🔊 Audio Testing

SpeakerTest generates audio separately for the left and right channels.

The purpose is to help determine whether the left and right audio channels are working correctly.

## ⚠️ Important

Some computers, headphones, Bluetooth devices, audio drivers, or Windows audio settings can mix stereo audio into both channels.

If both sides play the same tone:

1. Check your Windows audio settings.
2. Check the selected output device.
3. Make sure the device supports stereo output.
4. Check your headphones or speakers.
5. Try another audio output device.

Bluetooth devices may process stereo audio differently depending on the device and driver.

# 🚀 Running From Source

Clone the repository:

```bash
git clone https://github.com/Gavinr622/SpeakerTest.git
cd SpeakerTest
```

Install the dependencies:

```bash
py -m pip install -r requirements.txt
```

Run the application:

```bash
py app.py
```

# 📦 Building the EXE

The repository includes:

```text
build.bat
```

Run:

```text
build.bat
```

The finished application will be created at:

```text

```

You can then run the generated executable without manually launching Python.
